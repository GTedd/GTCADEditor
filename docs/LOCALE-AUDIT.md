# 译名与 i18n 源码清单

历史清单日期：2026-11-10。下列计数是迁移前的静态清单；当前进度见下节。

## 2026-11-15：属性生效部位

- 属性修饰器的生效部位改用统一枚举译名流程，修复直接读取枚举 ID 导致的英文回显；独立编辑页与通用属性表单共用同一选项和摘要名称。
- 仅在实时枚举提供的候选上补齐译名，保留宿主／资源包译文及手输 ID；内置标签跟随界面语言。

## 2026-11-13：关于页跟随游戏语言

- 关于页标签、版本说明、作者说明、链接文案及复制反馈统一读取当前游戏语言，替代前一轮的固定英文方案。
- 无服务端模组只读提示及客户端快照字段使用同一套中英文语言文件。
- 更新日志正文继续读取中文 `CHANGELOG.md`；游戏名称仍以当前游戏语言包和注册表为准。

## 2026-11-12：统一 i18n（历史记录）

- 编辑器自有文案统一使用 `assets/cadeditor/lang/zh_cn.json` 与 `en_us.json`；前端 `I18n.t`、原生 `EditorI18n.tr` 共用这两份来源。
- 内置简体中文与英文，页面首次执行脚本前取得游戏语言；其他语言回退英文，资源包可覆盖编辑器翻译。
- 按请求玩家语言生成服务端提示，作用域结束后恢复，避免多人及单人内置服务器串用语言。
- 当时关于页介绍、链接与复制提示固定英文（已由 2026-11-13 方案替代）；更新日志正文继续读取同一份中文 `CHANGELOG.md`。
- 编辑器字段说明通过显式路径绑定，游戏预览名称从原版实际语言文件生成；不对用户内容、协议键或 NBT 做文字替换。
- `node tools/i18n-sync.cjs --check` 校验中英文键、参数、源码引用与生成文件；维护方式见 `docs/I18N.md`。

## 迁移前清单

- 页面源码（不含样例 data.js）有 3752 处含中文字符串，分布在 37 个文件。
- 其中 359 处原文与原版语言包条目相同；仅是复用候选，不能据文字相同绑定无关键。
- data.js 有 3058 处，单列为浏览器样例。
- labels.js 集中定义 20 组标签/配置。

这是字符串词法清单，不是完整 JS 语法分析或错误译名计数；包含编辑器按钮、说明、诊断、回退及格式片段。完整位置与原文可运行 `python tools/locale-inventory.py` 生成；`docs/locale-inventory.json` 仅在本地保留。

## 本轮已修正

- uncommon：优秀 → 少见；common：普通 → 常见。rare 仍为稀有，epic 仍为史诗。卡片、表单和摘要统一来源。
- 实时游戏枚举译文优先，修复手写标签覆盖译名的问题。
- 游戏模式 4 项使用 gameMode.*；装备属性生效位置 11 项使用 item.modifiers.*。
- 热带鱼图案、烟花形状、染料/文本颜色使用语义匹配的游戏键。
- 方块名称先取 block 注册表，避免 carrots 被英文物品回退名抢先覆盖。
- powered 字段标签按要求改为激活，NBT 字段名不变。

## 本地文案与尚未迁移的类别

- 方块状态名及值、NBT 行为开关和实体字段说明：原版通常没有直接对应的语言键。
- 属性运算短名、候选分类、附魔标签分类、保险库分区属于本地操作文案。
- 稀有度：三版 zh_cn.json 没有 rarity.*；使用 Wiki 术语回退，资源包提供真实译文时优先读取。
- 装备槽短名仍有本地标签；生效位置整句已改用游戏语言键。
- 页面标题、按钮、设置和诊断仍有直接中文；项目尚未完成整套界面的多语言化。

## 权威名称的现有路径

物品、方块、实体、附魔、属性和效果等候选来自当前游戏实时注册表/description；不得用 data.js 或手写别名覆盖实时译文。
